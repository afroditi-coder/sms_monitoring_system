# sms_monitoring_system
This project is a SQL-based database system designed for remote server monitoring.
The system collects server metrics, detects issues automatically using alert rules, and sends notifications through SMS or Viber.

The database was designed using relational database principles and includes monitoring, alert management, and notification tracking functionalities.

Features
Remote server monitoring
Performance metric tracking
Automated alert generation
SMS and Viber notification support
Relational database design
Mock data for testing and demonstration
