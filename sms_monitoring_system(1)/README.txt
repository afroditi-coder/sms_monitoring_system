SMS/Viber Remote Server Monitoring System

This project contains a database design for a monitoring system that:
- Stores server metrics
- Generates alerts
- Sends SMS/Viber notifications
- Integrates with a CRM system (Contacts table)

How to use:
1. Run the SQL file in PostgreSQL
2. Review tables and relationships
3. Use mock data to test queries

Note:
In a real system, Contacts would be synced from CRM via API.
